# 所有列表任务名称取消跳转 — 功能规格说明书

> 版本：V1.0
> 日期：2026-07-22
> 状态：已实施，交互验收由用户执行
> 适用页面：计划外普查任务管理、计划外普查任务、我的计划外普查任务

## 一、功能定义

统一取消所有计划外普查列表中“任务名称”的点击和跳转能力。任务名称仅承担识别任务的展示作用；进入详情、填报或编辑等业务页面必须通过右侧“操作”列完成，避免同一行存在含义重复的入口。

## 二、影响范围

| 列表 | 文件 | 任务名称调整 | 操作列 |
|------|------|--------------|--------|
| 计划外普查任务管理 | `plan-outside-survey-task-list.html` | 链接改为普通文本 | 保留详情、编辑 |
| 计划外普查任务 | `plan-outside-survey-task-items.html` | 所有普查原因均改为普通文本 | 保留设置人员、下发、详情 |
| 我的计划外普查任务 | `plan-outside-survey-task-worker.html` | 链接样式改为普通文本 | 保留查看、填报、上报、撤回等现有操作 |

本次不调整站点名称、项目名称、楼栋名称、附件名称及其他可点击字段。

## 三、用户故事

### User Story 001

- **Summary:** 统一从操作列进入任务业务页面，减少列表入口歧义

#### Use Case

- **As a** 计划外面积普查任务处理人员
- **I want to** 在任务列表中将任务名称作为纯展示信息，并从操作列选择具体操作
- **so that** 我能明确区分查看、填报、编辑等业务意图，避免误点任务名称进入非预期页面

#### Acceptance Criteria

- **Scenario:** 三个任务列表展示不可点击的任务名称
- **Given:** 用户进入任一计划外普查任务列表
- **and Given:** 列表中存在任务数据
- **When:** 用户查看任务名称单元格
- **Then:** 任务名称以普通文本展示，不具备链接、点击跳转、链接光标或悬停反馈

### User Story 002

- **Summary:** 保留操作列作为唯一业务入口

#### Use Case

- **As a** 需要处理任务的业务人员
- **I want to** 从操作列选择详情、查看、填报或编辑
- **so that** 每次页面跳转都对应明确的业务动作

#### Acceptance Criteria

- **Scenario:** 使用操作列进入业务页面
- **Given:** 任务名称不可点击
- **and Given:** 当前任务具有可用操作
- **When:** 用户点击操作列中的业务动作
- **Then:** 系统继续按照该动作原有路由进入对应页面

## 四、业务流程

```mermaid
flowchart LR
  A[进入任一任务列表] --> B[查看任务名称普通文本]
  B --> C{是否需要处理任务}
  C -->|否| D[继续浏览或筛选]
  C -->|是| E[定位右侧操作列]
  E --> F[选择详情/查看/填报/编辑等动作]
  F --> G[进入动作对应页面]
```

## 五、展示规则

- 任务名称单元格不包含 `<a>`、`href`、点击事件或可交互角色。
- 保留各列表现有字号、字重、行高、截断和列宽，不因移除链接改变表格布局。
- 移除链接蓝色、下划线、手型光标及悬停颜色变化。
- 趸售用户与其他普查原因使用相同规则，不再对任务名称做条件分支。
- 操作列路由、权限显隐、任务状态判断和固定列行为保持不变。

## 六、异常与边界

- 无操作权限的任务仍按现有规则展示可用操作，本次不新增权限判断。
- 操作列因宽度不足产生横向滚动或固定展示时，继续沿用现有表格行为。
- 空列表不受影响。
- 任务名称过长时沿用当前换行或截断策略，不新增 Tooltip。
- 本次只减少 DOM 交互节点，不增加数据请求、计算或分页压力。

## 七、验收标准

```gherkin
场景: 计划外普查任务管理名称不可点击
  假如 页面存在计划外普查任务
  当 用户查看任务名称
  那么 名称为普通文本
  并且 只能通过操作列“详情”或“编辑”进入业务页面

场景: 计划外普查任务名称不可点击
  假如 页面包含不同普查原因的任务
  当 用户查看任一任务名称
  那么 所有名称均不可点击
  并且 操作列“详情”继续按普查原因进入正确详情页

场景: 我的计划外普查任务名称不可点击
  假如 页面存在分配给当前人员的任务
  当 用户查看任务名称
  那么 名称不显示链接交互
  并且 查看、填报、上报和撤回仍由操作列承载

场景: 其他名称字段保持不变
  当 用户查看站点、项目、楼栋或附件名称
  那么 这些字段继续执行修改前的展示和交互规则
```

- 保留各列表当前文字层级，去除链接视觉和交互。
- 其他名称字段不调整。
