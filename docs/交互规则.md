## 一、全局交互约定

### 1.1 页面架构

- 所有页面为**独立 HTML 文件**，非 SPA
- 页面间使用**相对路径**跳转
- 通用样式基座：`pc-template-base.css`
- 设计规范参考：`style-guide.md`
- 目标宽度：桌面端，表格最小宽度 1440px

### 1.2 侧栏菜单

```
┌─ 计划外面积普查（一级，可点击展开/收起）
│  ├─ 计划外普查任务管理（二级，active 时高亮）
│  ├─ 计划外普查任务（二级）
│  ├─ 我的计划外普查任务（二级）
│  └─ 计划外普查站点明细（二级，仅计划经营部）
└─ 面积普查（并列一级，无二级菜单，点击进入占位页）
└─ 其它模块（待扩展）
```

| 规则 | 说明 |
|------|------|
| 展开/收起 | 点击一级菜单项 `.menu-parent` 切换二级菜单 `.menu-child` 的显示 |
| 动画 | 箭头图标旋转 180°（`.menu-arrow.collapsed`） |
| 状态保持 | 当前：不保持，每次刷新重置展开 [待确认] |
| 面积普查入口 | 所有现有页面和所有演示角色显示；不参与计划外菜单展开/收起 |

### 1.3 顶栏用户身份

当前为**演示模式**，顶栏显示固定身份：
- 列表页/新建页/站点级任务页：`计划管理部/业务管理员`
- 详情占位页/编辑占位页：`计划经营部`

> [待确认] 正式版需实现角色切换或基于登录的用户身份自动显示

| 起点 | 终点 | 触发方式 | 参数 |

| 新建页 | 列表页 | 点击返回箭头 ← | 无 |
| 详情页 | 列表页 | 点击"返回任务列表" | 无 |
| 编辑页 | 列表页 | 点击"返回任务列表" | 无 |
| 站点级任务页 | 详情页 | 点击操作列“详情” | `?id={siteCode}` |
| 站点级任务页 | 列表页 | 侧栏菜单点击 | 无 |
| 我的计划外普查任务 | 趸售用户站点详情 | 点击趸售用户任务“查看” | `?id={siteCode}` |
| 趸售用户站点详情 | 项目详情弹窗 | 点击普查项目“查看” | 项目 ID（页内） |

**任务名称与操作入口补充：**

- 三个计划外普查任务列表的任务名称均为不可点击文本，所有业务跳转统一由操作列承载。
- `source=items` 返回计划外普查任务；`source=worker` 返回我的计划外普查任务。
- 趸售详情按站点编码读取审核上下文：`60218B007` 为主任审核，`60218B013` 为片区所审核。

### 2.2 URL 参数约定

| 参数 | 含义 | 使用页面 |
|------|------|----------|
| `id` | 任务编号（如 `OUT-2026-001`） | 详情/编辑；详情页通过映射定位站点 |
| `id` | 站点编码（如 `60218B001`） | 站点级→详情；详情页直接定位站点 |

> 详情页已兼容两种 `id` 格式；未知或缺失参数在原型中回退至默认站点。

> 趸售用户站点详情仅接受其演示站点/任务标识；未知参数展示专用空状态，不执行默认站点回退。

## 三、筛选交互规则

### 3.1 任务管理列表页

| 筛选项 | 类型 | 匹配方式 | 默认值 |
|--------|------|----------|--------|
| 任务名称 | 文本 | 模糊匹配（`indexOf`） | 空 |
| 普查原因 | 下拉 | 精确匹配 | 全部 |
| 所属管理部 | 下拉 | 精确匹配 | 全部 |
| 任务状态 | 下拉 | 精确匹配 | 全部 |
| 开始时间 | 日期 | `>=` 匹配 | 空 |
| 结束时间 | 日期 | `<=` 匹配 | 空 |

**交互行为：**
- 点击"查询"：组合所有非空条件，筛选后重置到第 1 页
- 点击"重置"：清空所有条件，恢复全部数据，回到第 1 页
- 回车键：在任意输入框中按 Enter 触发查询
- 无匹配结果：显示空状态"暂无匹配任务，请调整筛选条件后重试。"
- 筛选区字段和输入框同行水平排列（`.filter-grid-4`，4列 + 操作按钮）
- **与规格文档差异：** 规格文档定义了"站点名称/编码"筛选，但当前代码中未实现

### 3.2 站点级任务页

| 筛选项 | 类型 | 匹配方式 | 默认值 |
|--------|------|----------|--------|
| 站点编码 | 文本 | 模糊匹配 | 空 |
| 站点名称 | 文本 | 模糊匹配 | 空 |
| 站点类型 | 下拉 | 精确匹配 | 全部 |
| 下发状态 | 下拉 | 精确匹配（未下发/已下发） | 全部 |
| 审核状态 | 下拉 | 精确匹配（待填报/所长审核/专工审核/主任审核/审核通过/已退回） | 全部 |
| 开始时间 | 日期 | 最近操作日期 `>=` 匹配 | 空 |
| 结束时间 | 日期 | 最近操作日期 `<=` 匹配 | 空 |

**Tab 切换：**
- 普查原因以 Tab 形式展示（全部/面积变化/一管到户/新开户及增容/趸售用户）
- 每个 Tab 带计数（如"面积变化 3"）
- 切换 Tab 时重置分页到第 1 页
- Tab 与筛选条件组合应用

**交互行为：**
- 同列表页：查询/重置/回车触发/空状态
- 下发状态、审核状态与其他筛选条件及普查原因 Tab 使用 AND 关系组合过滤
- 最近操作时间表头支持“默认 → 降序 → 升序 → 默认”循环切换；排序在筛选之后、分页之前执行
- 设置普查人员成功后仍保持“未下发”，并刷新最近操作时间
- 点击“下发”成功后切换为“已下发”，审核状态保持“待填报”，并刷新最近操作时间
- 重置时同时清空状态筛选和时间排序，恢复原始数据顺序

### 3.3 我的计划外普查任务页

- 表格不展示“任务状态”和“下发状态”列，保留审核状态、最近操作时间和操作列。
- 任务状态筛选继续使用内部 `status` 字段，不因展示列删除而失效。
- 填报、上报、撤回、查看等操作继续依据内部任务状态判断。
- 空结果横跨精简后的全部 10 列。

### 3.4 新建页站点弹窗

| 筛选项 | 类型 | 匹配方式 |
|--------|------|----------|
| 管理部 | 下拉 | 精确匹配 |
| 片区所 | 下拉 | 精确匹配 |
| 站点类型 | 下拉 | 精确匹配 |
| 站点名称 | 文本 | 模糊匹配（名称或编码） |

### 4.4 片区所审核弹窗 ✅ 已确认（2026-07-22）

- 当前按片区所审核角色演示。
- 默认选择“不通过”，显示退回节点“普查人员填报”，审批意见必填。

### 4.5 楼栋详情差异化展示 ✅ 已确认（2026-07-22）

- 打开楼栋详情时，必须使用当前详情上下文中的站点类型重新计算内容显隐。
- 用户站不录入变更明细，因此隐藏“变更详情”标题及明细表，隐藏后不保留空白区域。
- 用户站仍展示楼栋基础信息、原面积、现面积、变化、变化率、普查依据附件及备注。
- 自管站继续展示完整变更详情。
- 从用户站切换到自管站或反向切换时，不得沿用上一次弹窗的显隐状态。

## 五、表格交互规则

### 5.1 通用表格规范

| 规则 | 说明 |
|------|------|
| 表头 | 不换行（`white-space: nowrap`），使用次要色文字 |
| 缺失字段 | 标记为 `-`，不删除列 |
| 重要数据 | 用 `<strong>` 加重 |
| 操作列 | 用 `.action-row` 包裹链接 |
| 空状态 | 居中显示提示文案 |
| 横向滚动 | 列数过多时 `.table-scroll` 提供横向滚动 |

### 5.2 分页

| 页面 | 每页条数 | 分页控件 |
|------|----------|----------|
| 任务管理列表 | 5 条 | 上一页 / 页码 / 下一页 |
| 站点级任务页 | 10 条 | 上一页 / 页码 / 下一页 |
| 站点选择弹窗 | 未分页 [待确认] | 无 |

**分页规则：**
- 序号按当前分页结果连续编号（非全局序号）
- 首页/末页时上一页/下一页按钮禁用
- 当前页码高亮（`.page-number.active`）
- 显示总数统计（如"共 13 条"）

### 5.3 进度展示

| 场景 | 展示方式 |
|------|----------|
| 任务完成统计 | `已完成数 / 总数` + 进度条 + 百分比 |

### 11.4 操作
