### 2.7 自管站楼栋填报

| 属性 | 内容 |
|------|------|
| **文件** | `plan-outside-survey-task-self-fill.html` |
| **路由** | 我的计划外普查任务 → 填报链接 → 本页；URL 参数 `?id={siteCode}` |
| **状态** | ✅ 已完成（基础版） |
| **角色** | 普查员（演示） |
| **适用范围** | 自管站站点（用户站后续另起一页） |

**功能概述：** 普查员为自管站添加/导入楼栋或建筑物数据，填写完成后可暂存或上报。顶部展示站点基本信息与附件上传区；中部展示分类统计；底部为操作栏。

**包含组件：**
- 顶部双卡：站点信息卡（站点名称、换热站编码、用热地址、所属管理部、所属片区所、行政区、办事处、普查人员）+ 附件上传卡（上传门头照、上传平面图）
- 统计双卡：任务总面积（参考）+ 本次填报面积；分类小计：住宅/非住宅；细类：多层/公寓/高层/非居

- 空状态：图标 + "需要添加楼栋或建筑物数据后才能进行数据上报" + 添加按钮
- 底部固定操作栏：取消 / 暂存 / 上报
- 导入弹窗：拖拽上传 .xls/.xlsx（≤20MB），含下载模板链接
- 添加楼栋弹窗：占位，提示"该功能将在后续版本中开放"

**关联页面：**
- ← 从 worker 页面"填报"链接进入

**业务规则：**
- 站点信息按 URL `id` 参数从模拟数据动态渲染（默认 `60218B001` 春江花月西站）
- 站点未在演示数据中时 fallback 到默认站点
- 楼栋数据为空时，"上报"按钮会提示"尚未添加任何楼栋数据"，无法提交
- 上传门头照/平面图/导入 Excel/添加楼栋均为占位，提示"功能将在后续版本中开放"

### 2.8 趸售用户站点详情

| 属性 | 内容 |
|------|------|
| **文件** | `plan-outside-survey-task-dh-detail.html` |
| **路由** | 计划外普查任务/我的计划外普查任务 → 趸售用户任务“详情/查看” → 本页；`?id={siteCode}&source={items/worker}` |
| **状态** | ✅ 已完成 |
| **角色** | 片区所审核人员（演示） |

**功能概述：** 纯只读展示趸售用户站点信息、自动面积统计及3条普查项目。项目“查看”打开只读项目详情，依次展示项目信息、附件预览占位、项目统计和楼栋明细；右侧展示审批记录并保留审核流程操作。

**业务规则：**
- 站点、项目和楼栋数据不可编辑；审核仅更新流程状态和审批记录。
- 站点与项目面积根据各项目楼栋自动汇总，本次填报面积只纳入普查状态为“完成”的楼栋。
- 普查明细表、平面图和楼栋附件只展示静态预览占位，不加载或下载真实文件。
- 未知 `id` 参数展示“未找到趸售用户站点”，不回退到普通站点。
- 宽表支持横向滚动，普查项目操作列固定在右侧。
- 三个计划外普查任务列表中的任务名称均不可点击；趸售任务仅通过操作列“详情”进入本页。
- `60218B007` 展示裕华区东南站并按管理部主任审核规则处理；`60218B013` 保留个人任务入口上下文。
- 返回地址由 `source=items/worker` 决定。
