## 三、核心业务流程

### 3.1 任务管理主流程

```mermaid
flowchart TD
  A[计划经营部/管理部创建任务] --> B[填写任务基本信息]
  B --> C[选择普查站点范围]
  C --> C1{站点来源}
  C1 -- 从站点库 --> D[弹窗筛选并勾选站点]
  C1 -- 新增临时 --> E[填写临时站点信息]
  C1 -- 导入Excel --> F[上传站点清单文件]
  D --> G[确认保存]
  E --> G
  F --> G
  G --> H[任务状态：待分配]
  H --> I[所长分配普查人员]
  I --> J[任务状态：进行中]
  J --> K[普查人员填报面积]
  K --> L[提交审核]
  L --> M{审核流程}
  M -- 退回 --> J
  M -- 通过 --> N{终审}
  N -- 管理部审核通过 --> O[任务状态：已结束]
```

### 3.2 审核流程 ✅ 已确认

```
普查人员填报完成并提交
      ↓
  片区所审核 ──── 退回 → 只能：普查人员填报
      ↓ 通过
  管理部专工审核 ──── 退回 → 可选择：片区所审核 / 普查人员填报
      ↓ 通过
  管理部主任审核 ──── 退回 → 可选择：管理部专工审核 / 片区所审核 / 普查人员填报
      ↓ 通过
  已结束
```

**审核链：** 片区所审核 → 管理部专工审核 → 管理部主任审核（三级串行）

**退回选项（由业务确认，2026-07-21）：**

| 当前审核节点 | 可退回的选项 |
|-------------|------------|
| 管理部主任审核 | 管理部专工审核 / 片区所审核 / 普查人员填报 |
| 管理部专工审核 | 片区所审核 / 普查人员填报 |
| 片区所审核 | 普查人员填报 |

**规则：** 每个审核节点可退回到自身以下任意层级，从四个选项中过滤出当前节点"之下"的选项。

**片区所审核原型交互（2026-07-22）：**

- 通过：进入专工审核，审批意见选填。
- 不通过：只能退回普查人员填报，审批意见必填。
- 提交后同步更新详情页状态，并将本次结果插入审批记录顶部。

> ⚠️ 注意：此前确认"所长审核"为审核节点名称，但退回选项中称为"片区所审核"——需确认这两个名称是否需要统一。[待确认]

### 3.4 站点级任务状态展示 ✅ 已确认（2026-07-22）

站点级“计划外普查任务”列表不再使用单一“任务状态”展示和筛选，拆分为两个独立维度：

- **下发状态：** 未下发 / 已下发。设置普查人员后仍为“未下发”，只有点击“下发”成功后才变为“已下发”。
- **审核状态：** 待填报 / 所长审核 / 专工审核 / 主任审核 / 审核通过 / 已退回。
- **最近操作时间：** 最近一次分配、下发、填报、审核或退回的时间，展示到分钟；操作成功后刷新。

```mermaid
flowchart LR
  A[设置普查人员] --> B[下发状态：未下发]
  B --> C[点击下发]
  C --> D[下发状态：已下发]
  D --> E[审核状态：待填报]
  E --> F[所长审核]
  F --> G[专工审核]
  G --> H[主任审核]
  H --> I[审核通过]
  F -->|退回| J[已退回]
  G -->|退回| J
  H -->|退回| J
```

列表支持按下发状态、审核状态组合筛选，并按最近操作时间升序或降序排序。数据处理顺序固定为：条件筛选 → 时间排序 → 分页。

### 3.5 计划外普查站点明细流程 ✅ 已确认（2026-07-22）

计划经营部可查看全部计划外任务中的站点。同一站点只展示最新任务的完整业务快照，处理顺序固定为：全部任务站点 → 按站点去重选最新 → 顶部条件与组织条件组合筛选 → 分页。组织树支持管理部/片区所单选，其中选择管理部包含其全部下属片区所。

```mermaid
flowchart TD
  A[计划经营部进入站点明细] --> B[读取全部计划外任务站点]
  B --> C[按站点唯一键分组]
  C --> D[按任务创建时间和任务编号选择最新记录]
  D --> E[顶部条件与组织条件AND筛选]
  E --> P[分页]
  P --> F{选择操作}
  F -->|详情| G[打开最新任务站点详情]
  F -->|同步| H{已完成且审核通过?}
  H -->|是| I[确认并幂等同步正式站点数据]
  H -->|否| J[禁止同步]
  F -->|退回| K{已有完成结果且未同步?}
  K -->|是| L[填写退回原因]
  L --> M[退回普查人员填报]
  M --> N[普查状态=进行中 审核状态=已退回]
  K -->|否| O[禁止退回]
```

- 同步后的结果禁止直接退回；需要纠错时通过新任务重新普查。
- 退回原因必填，统一退回普查人员填报；原完成与审批记录作为历史保留。
- 组织树默认全部展开且不选择组织；搜索只过滤树节点，组织重置清空搜索与选择并展开全部管理部。
- 原型仅模拟页面内状态变化，正式系统必须使用结果版本、幂等键、事务和操作日志。
